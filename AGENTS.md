# CEP Fácil — desenvolvimento diário

Projeto independente em HTML, CSS e JavaScript puro, sem backend de produção. Destino autorizado pelo usuário: `joao-azevedoo/cep-facil`. A versão completa anterior em `../projeto-cep/` é apenas referência; não enviá-la para este repositório.

- Leia `PLANO_DIARIO.md`, `estado.json` e `CHANGELOG.md` antes de trabalhar.
- Implemente no máximo **um novo incremento por dia**, na ordem dos sete incrementos do enunciado. Use a data real em America/Sao_Paulo. Não mude datas de commits e não antecipe funcionalidades dos próximos dias.
- Cada incremento deve produzir uma mudança funcional e verificável, explicação no README, verificação proporcional e um commit com mensagem em português.
- Faça commits exclusivamente neste repositório independente. Não incluir arquivos, credenciais ou metadados do Agro Check ou do projeto completo anterior.
- Não trocar a identidade do autor Git por uma conta não autenticada. A identidade global deste computador pertence a MatFernandex; a titularidade desejada do repositório é joao-azevedoo. Preserve a autoria efetiva dos commits.
- Consulte `estado.json` e o histórico Git para evitar repetir a etapa ou avançar duas etapas no mesmo dia. Se houver mudanças do usuário, preserve-as; não fazer reset, force-push ou reescrita de histórico.
- A autenticação atual não alcança a conta de destino. Antes de publicar, confirme acesso de escrita a `joao-azevedoo/cep-facil`, pela conta conectada de joao-azevedoo ou por colaboração autorizada. Não criar outra publicação em MatFernandex.
- Enquanto o envio da etapa atual estiver pendente, não implementar a seguinte. Depois de recuperar acesso, envie a etapa pendente; registre a data efetiva da publicação. Se isso atrasar o cronograma, informe o atraso.
- Publicação do site no GitHub Pages é a etapa 7. As etapas anteriores atualizam o código no GitHub quando houver acesso; a prévia local pode ser usada para revisão.
- Tokens Organic ficam em `css/tokens.css`, copiados de `packages/tokens`. Estilos próprios usam suas variáveis. Não copiar markup de `docs/design/`. Nomes de domínio e comentários em português.
- Não armazenar segredos. `.operacao/` e arquivos ZIP são locais e ignorados. A rotina automática deve encerrar em 12/10/2026 ou quando as sete etapas forem concluídas, o que acontecer primeiro, relatando pendências se existirem.
