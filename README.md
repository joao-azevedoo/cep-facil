# CEP Fácil

O CEP Fácil é um sistema para consultar endereços pelo CEP. Ele mostra rua, bairro, cidade e UF, além do nome do estado e da região quando disponíveis.

- Aceita CEPs com ou sem hífen.
- Salva até cinco consultas recentes neste navegador.
- Permite reabrir consultas e limpar o histórico.
- Permite cancelar uma busca ou consultar outro CEP.
- Usa uma fonte alternativa quando o serviço principal está indisponível.

Funciona no navegador e precisa de conexão com a internet.
